The run

Each call has three slips. Sent is the request: system prompt and tools (identical every turn, so cached) and the messages. Model replied is the model's answer and the tools it chose. Engine is what the code did with each tool call, and the result that goes back to the model in the next call. A thick line on the left is a lane; a horizontal line is agents starting (lanes open) or reporting/merging back (lanes merge).
